# FACEIT V2 — продуктовый бриф

Дата решения: 2026-11-11  
Статус: принято владельцем проекта  
Рабочая ветка: `faceit-dev`

## Главная идея

Профильный интерфейс становится **основным сайтом CS2 Analytics**. Мы не поддерживаем два продукта — старый сайт и отдельный аккаунт/профиль. У пользователя всегда одна цельная оболочка, а профильный shell FACEIT-inspired становится основой навигации по всему продукту.

Профиль — не просто личная страница и не отдельное приложение. Это основной app shell, внутри которого открываются как персональные, так и общие разделы.

## Принципы

1. **Одна оболочка.** Переходы между профилем, статистикой, матчами и другими разделами не должны ощущаться как переход на другой сайт.
2. **Один источник данных.** Глобальные страницы и персональные вкладки профиля используют общие сущности и расчёты, не копии данных.
3. **Функции старого сайта сохраняем, старый интерфейс — нет.** Переносим нужную функциональность, но не обязаны сохранять каждую старую страницу/кнопку.
4. **Убираем лишнее.** Неактуальные, дублирующие, декоративные элементы удаляются или скрываются.
5. **Нет мёртвых controls.** Каждая видимая кнопка, вкладка, ссылка и заголовок с affordance должны выполнять понятное действие. Если функция ещё не реализована — control не показываем как рабочий.
6. **Сначала точность.** ELO, winrate, K/D, impact, match history и другие показатели сверяются с одной канонической логикой.
7. **FACEIT — ориентир, не копия.** Сохраняем удобную иерархию и знакомое расположение элементов, но постепенно развиваем собственный стиль.
8. **Безопасная среда.** Все текущие изменения — только в `faceit-dev`; production branch и production Supabase не трогаем без отдельного разрешения.

## Предварительная карта разделов

Это рабочая карта для аудита, не окончательная фиксация названий/порядка:

- **Overview / Home** — главная панель и сводка.
- **Track** — общая история/динамика и персональный Track игрока.
- **Players** — список игроков и переходы в профили.
- **Matches / Series** — список матчей, серии и детальные страницы.
- **Maps** — карты, статистика и результаты.
- **Teams** — составы, сравнения и командная аналитика.
- **Records** — общие рекорды и персональные достижения.
- **Seasons** — сезоны, таблицы, личный прогресс и архив.
- **Settings / Account** — профиль, авторизация, настройки.

Внутри страницы игрока остаются профильные tabs и персональные представления тех же данных. Не нужно создавать отдельные независимые версии Track, Matches или Seasons.

## Критерии готовности

FACEIT V2 не считается готовым, пока:
- пользователь не может попасть в тупик или на визуально рабочую, но мёртвую кнопку;
- все нужные разделы доступны из одной оболочки;
- account/profile и глобальная навигация работают как единый продукт;
- данные и показатели согласованы между страницами;
- основные сценарии покрыты тестами и browser QA;
- DEV deployment SHA подтверждён;
- документация отражает фактический код, а не планы.

## Что не делаем сейчас

- Не переписываем приложение с нуля.
- Не импортируем заново DEV data без аудита.
- Не запускаем SQL migrations только ради восстановления frontend.
- Не копируем данные FACEIT-профиля OBASRAL.
- Не трогаем production/main.
- Не считаем PWA `display: standalone` доказательством отдельного программного движка.
