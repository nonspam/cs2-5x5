Design-only experimental branch based on the user-provided RADICAL UI V3 / TRAIN MAPS archive.

Focus of this pass:
- black/graphite UI with lime interface accents;
- green/red semantic colors for K/D, K-D, impact, form, stability, winrate and map stats;
- restore normal player nickname casing and alignment in Dynamic Stats controls/legend;
- remove blue hover/focus/active chrome from navigation and controls;
- restyle Player Profile FORM, MAPS, recent detailed maps and ERAS to the new black/lime visual language;
- restyle Teams player controls and drag states;
- fix map catalogue photo rendering using real `<img>` elements with consistent `object-fit: cover` geometry;
- preserve selected-map atmospheric background behavior.

Data files were not changed.
